One-star review of Monday, written as if Monday were a restaurant — 20 words, one line:

> One star. Seated at the worst table, served cold coffee and a 9am meeting, then billed for the whole week.

## Run it

```sh
node main.ts
```

Writes the review to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
